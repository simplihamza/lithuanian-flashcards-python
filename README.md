# Flashy 🃏

A flashcard-based language learning app built with Python, `tkinter`, and `pandas`. Displays a word, auto-flips to reveal its translation, and tracks which words you still need to learn, saving your progress between sessions.

> 🚧 **Work in progress** -> this project is being built incrementally. Check the commit history for the latest progress and features added.

## Features (planned / in progress)
- [ ] Load word data from a CSV file using pandas
- [ ] Display a random word on a card
- [ ] Auto-flip the card after a few seconds to reveal the translation
- [ ] Mark a word as "known" and remove it from the learning pool
- [ ] Persist progress to a CSV, so learned words don't reappear next session
